Phase 2 - Docker & AWS EC2 ✅

Implemented a CI/CD pipeline using GitHub Actions, AWS OIDC, Amazon ECR and AWS Systems Manager. Every push to the main branch automatically builds a Docker image and deploys the latest version to AWS EC2.
